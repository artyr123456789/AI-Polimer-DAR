#### 1. Описание проекта

Данный проект представляет собой систему предиктивной аналитики на основе Gaussian Process Regression (GPR). Модель предназначена для предсказания физико-химических и механических свойств полимерных композитов на основе их состава, структуры (SMILES) и условий получения.

Особенностью решения является использование кастомного ядра MixedTanimotoRobust, которое эффективно работает с комбинацией бинарных признаков (наличие структурных фрагментов) и непрерывных величин (температура, давление, массовые доли), учитывая пропуски в данных.

#### 2. Технологический стек
*   **Core:** `Python 3.10+`, `NumPy`, `Pandas`
*   **Cheminformatics:** `RDKit` (извлечение молекулярных дескрипторов)
*   **Machine Learning:** `Scikit-learn` (GPR, RFE, StandardScaler, Pipeline)
*   **Optimization:** `Optuna` (TPE Sampler для поиска гиперпараметров)
*   **Validation:** `RepeatedKFold`, `Scipy` (Spearman correlation, Normal distribution)
*   **Architecture:** `Dataclasses`, `Pathlib`

ML Model: Gaussian Process Regressor (GPR).

Algorithms: K-Fold Cross-Validation, Grid Search для оптимизации гиперпараметров ядра.

Metrics: 
𝑅2, RMSE, Spearman Correlation, PICP (Prediction Interval Coverage Probability).

#### 3. Структура данных
Для обучения модели требуются два файла в формате Excel, которые должны быть загружены в корень проекта:

data_dataset.xlsx (Данные экспериментов):

Содержание: Рецептуры, массовые части компонентов, параметры оборудования (температура, циклы переработки, время реакции), механические свойства (Разрушающее напряжение, Ударная вязкость и др.).

property_dataset.xlsx (Свойства компонентов):

Содержание: Справочные данные по компонентам (SMILES-строки, Плотность, ПТР, Модуль упругости, температуры плавления и стеклования).

#### 4. Инструкция по запуску

Откройте ноутбук в Google Colab по ссылке выше.

Загрузите файлы data_dataset.xlsx и property_dataset.xlsx во временное хранилище (иконка папки слева).

Запустите все ячейки (Runtime -> Run all).

Процесс обучения:

Модель автоматически проведет очистку данных и обработку пропусков через MaskedStandardScaler.

Для каждого целевого показателя (Target) будет проведен поиск оптимальных гиперпараметров (Length Scale и Noise Level).

По завершении обучения будет выведен подробный отчет с метриками на тестовой выборке.

#### 5. Выходные данные (Production Ready)

После выполнения скрипта в корневой директории будет создан архив models.zip, содержащий:

.joblib файлы — обученные модели для каждого целевого признака. Внутри сохранены веса, обучающая выборка (необходима для GPR) и параметры скейлера. overall_metrics.json — отчет со всеми показателями точности (𝑅2, RMSE и др.) для оценки качества модели.

#### 6. Архитектура кода (В процессе рефакторинга)

Текущая версия проекта переходит от экспериментального Notebook-формата к модульной архитектуре:

FullAdditiveRobustKernel — кастомное ядро для работы со смешанными типами данных.

MaskedStandardScaler — обработка признаков с учетом отсутствующих значений (-999.0).

Pipeline: Модули обучения теперь поддерживают автоматический экспорт весов для дальнейшего деплоя.

Note: Код находится в стадии активного рефакторинга. Закомментированные блоки в ноутбуке относятся к экспериментальным проверкам альтернативных архитектур ядер и будут удалены в финальной версии.

#### 7. Метрики качества

Модель оптимизируется не только под точность 𝑅2, но и под калибровку уверенности (метрика PICP). Это позволяет заказчику понимать интервал достоверности каждого предсказания, что критически важно в химическом производстве.
